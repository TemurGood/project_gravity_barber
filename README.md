# 💈 GRAVITY BARBER LOUNGE — Система автоматизации барбершопа

Премиальный лендинг, интерактивный календарь онлайн-записи, Telegram-бот и панель администратора для управления персоналом, графиком и нагрузкой мастеров.

---

## 🚀 Возможности проекта

1. **Премиальный лендинг (UI/UX в стиле TemplateMonster 566517)**:
   - Темная благородная атмосфера (матовый графит, античное золото, винтажные акценты).
   - **Hero-секция с видео-фоном YouTube**: зацикленное видео со стрижками без звука с затемнением. При каждой перезагрузке страницы случайным образом подгружается новое эстетичное видео о стрижках/фейдах.
   - **Прелоадер**: стилизованная анимация ножниц и золотого прогресс-бара, исчезающая при готовности страницы.
   - Параллакс-эффекты и плавное появление блоков при скролле.
   - Фирменное меню услуг с точечными разделителями цен, длительностью и фильтрацией по категориям.
   - Секция мастеров с фото, рейтингами, графиком работы и карточками.
   - Галерея/лукбук с лайтбоксом, отзывы гостей и блок локации с динамическим бейджем *«Открыто сейчас»*.

2. **Интерактивный календарь онлайн-записи**:
   - Клиент выбирает: **Услугу** -> **Барбера** -> **Дату** -> **Свободное время** -> **Контакты**.
   - Дни, в которые выбранный барбер отдыхает, автоматически блокируются.
   - Свободные тайм-слоты динамически рассчитываются с учетом графика мастера и уже существующих записей.
   - Моментальная анимация конфетти и квитанция с уникальным номером брони (`GRV-XXXX`).
   - Все заявки сразу отправляются в базу данных и дублируются в Telegram.

3. **Telegram-бот**:
   - Полноценная запись на стрижку прямо в мессенджере Telegram (`/book`).
   - Просмотр каталога услуг, мастеров и контактов.
   - **Моментальные уведомления в админский чат/группу** с кнопками `[✅ Подтвердить]` и `[❌ Отклонить]`.
   - При нажатии на кнопку подтверждения прямо в Telegram статус заявки синхронно обновляется в базе данных и в админ-панели!

4. **Панель управления (Admin Dashboard)**:
   - Доступна по кнопке *«Админка»* в шапке сайта.
   - **Мониторинг нагрузки барберов**: визуальная шкала занятости смены каждого мастера (% загрузки, сколько слотов занято из скольки возможных, список клиентов на сегодня).
   - **Управление барберами**: добавление новых мастеров, выбор рабочих дней недели (Пн, Вт, Ср...), часов смены (например 10:00 - 21:00), длительности стрижки, фото и квалификации.
   - **Управление записями**: фильтры по статусам (ожидают, подтверждены, завершены, отменены), ручное добавление записи администратором.
   - **Управление услугами**: редактирование каталога и цен.
   - **Настройка Telegram**: проверка связи кнопкой «Тест», ввод токена и Chat ID.

## 🛠️ Запуск проекта

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки (Сервер + Vite Frontend)
```bash
npm run dev
```
- Фронтенд запустится на: `http://localhost:5173`
- Бэкенд API запустится на: `http://localhost:3001`

### 3. Запуск готовой сборки
```bash
npm run build
npm start
```
Приложение откроется на: `http://localhost:3001`

## 📲 Как получить ID чата в Telegram

Подробная инструкция также встроена прямо в панель администратора (вкладка *«Telegram & ID чата»*):

### Способ 1: Для личных уведомлений администратору (в ЛС)
1. Откройте в Telegram официального бота **[@userinfobot](https://t.me/userinfobot)** или **[@getmyid_bot](https://t.me/getmyid_bot)**.
2. Нажмите **Start** (или напишите любое сообщение).
3. Бот ответит строкой с вашим цифровым ID (например: `123456789`).
4. Скопируйте это число и вставьте в админ-панели в поле **Telegram Admin Chat ID**.
*(Также можно отправить команду `/id` созданному боту нашего барбершопа).*

### Способ 2: Для общей группы мастеров/барберов
1. Создайте в Telegram группу (например: *«Заявки Gravity Barbershop»*).
2. Добавьте вашего бота в эту группу и назначьте его **Администратором**.
3. Добавьте в группу бота **[@RawDataBot](https://t.me/RawDataBot)** или перешлите любое сообщение из этой группы в бот **[@getmyid_bot](https://t.me/getmyid_bot)**.
4. Скопируйте ID группы (для групп он всегда начинается со знака минус, например: `-1001234567890`).
5. Вставьте полученный ID (с минусом) в поле **Telegram Admin Chat ID** и нажмите *«Сохранить»*.
